# CyberSec-Talent HUD 🛡️📊

A desktop security operations center and talent dashboard built with **PyQt6** and **Python**. This tool bridges real-time system security monitoring with developer skill tracking in a sleek, side-by-side dark-mode interface.

## Features
- **Security Operations Center**: Live security log execution window for monitoring open ports, connection status, and intrusion detection alerts.
- **Talent & Portfolio Panel**: Dynamic display tracking active developer projects, CTF lab completions, and repository updates.
- **Operations Command Console**: Quick-action controls for triggering system scans and toggling intrusion alarm states.

## Tech Stack
- **Python 3.x**
- **PyQt6** (GUI Layout & Event Loop)
- **psutil / sockets** (System Telemetry & Network Monitoring)
